# AI Interview

A Django-based AI mock interview application focused on realistic interview practice and production-ready web deployment.

## Overview

AI Interview provides a structured interview experience with AI-generated questions, interview sessions and feedback-oriented workflows.

## Key Engineering Work

- Django web application with modular interview flow
- OpenAI integration for AI-powered interview interactions
- Session-based interview state
- CSRF-aware request handling
- Production configuration for hosted deployment
- Gunicorn application server setup
- WhiteNoise-based static file serving
- Deployment-oriented environment configuration

## Tech Stack

**Backend:** Python, Django  
**AI:** OpenAI API  
**Web:** HTML, CSS, JavaScript  
**Production:** Gunicorn, WhiteNoise, Render

## Run Locally

```bash
git clone https://github.com/ssvprasad144/AI_interview.git
cd AI_interview
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Set the required environment variables before enabling OpenAI-powered functionality.

This project demonstrates hands-on work across AI integration, Django backend development, authentication/session handling, production configuration and deployment troubleshooting.
